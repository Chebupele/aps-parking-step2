# Архитектура программных систем

Материалы курсовой работы по дисциплине «Архитектура программных систем».

**Вариант 2 — мониторинг занятости парковок.**

Имитационная модель сервиса обработки кадров с камер парковок. По результатам анализа обновляется информация о свободных местах. При перегрузке из очереди удаляется самый старый кадр, а на обработку выбирается самый новый.

## Вариант 2

| Код | Расшифровка |
|---|---|
| ИБ | Источники бесконечного типа |
| ИЗ2 | Равномерное распределение интервалов между заявками |
| ПЗ1 | Экспоненциальное распределение времени обслуживания |
| Д1ОЗ1 | Постановка в буфер по кольцу |
| Д1ОО3 | Отказ самой старой заявке в буфере |

| Д2Б2 | Выбор заявки из буфера по LIFO |
| ОР2 | Результаты автоматического режима в виде графиков |
| ОД2 | Формализованная схема состояния системы в пошаговом режиме |
