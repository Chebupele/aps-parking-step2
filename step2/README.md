## Работа модели

Камеры независимо создают заявки с интервалами U(a, b). Диспетчер постановки записывает кадр в общий буфер по кольцу от УБ. Если места нет, удаляется самая старая ожидающая заявка, а новый кадр занимает её ячейку.

После прихода кадра или завершения обслуживания модель вызывает диспетчер выбора. Он ищет свободный прибор по кольцу от УП и передаёт ему самую новую заявку из буфера. Обслуживание длится Exp(mu). При занятости всех приборов заявки остаются в очереди, а модель переходит к следующему событию.

Оба диспетчера — программные алгоритмы. ДП имеет ссылки на буфер и статистику; ДВ — на буфер, приборы, календарь и статистику.

## Обозначения

- n — число камер, k — число приборов, M — ёмкость буфера; n, k, M >= 1.
- T — длительность моделирования; 0 < a < b, mu > 0, T > 0.
- УБ — ячейка, с которой начинается поиск места. После записи: УБ = (index + 1) mod M.
- УП — прибор, с которого начинается поиск свободного. После назначения: УП = (j + 1) mod k.
- ARRIVAL — поступление кадра, FINISH — завершение обслуживания.
- Возраст заявки определяется парой (createdAt, id). id выдаётся моделью последовательно, поэтому при равном времени старше заявка с меньшим id.

Поиски по кольцу ограничены M и k проверками. Заявки в массиве не сдвигаются. После каждого события ДВ назначает все возможные заявки; при непустом буфере все приборы заняты. При совпадении времени сначала обрабатывается FINISH, затем ARRIVAL. События одного типа и времени идут в порядке добавления.

Время передачи и действий диспетчеров равно нулю. При пустом буфере и свободном приборе кадр поступает на обслуживание в тот же момент. В T моделирование заканчивается без опустошения очереди; оставшиеся заявки учитываются отдельно.

## Статистика

В журнал заносятся генерация, постановка в буфер, выбивание, выборка, начало и завершение обслуживания. Статусы заявки: CREATED, WAITING, REFUSED, PROCESSING, DONE. Времена начала и завершения до соответствующего события равны -1.

Для каждой камеры собираются число заявок, доля отказов, среднее время ожидания, обслуживания и пребывания в системе, дисперсии ожидания и обслуживания. Временные показатели рассчитываются по завершённым заявкам. Загрузка прибора — доля занятого времени на интервале [0, T].

В пошаговом режиме показываются схема, календарь, журнал и указатели (ОД2), в автоматическом — графики результатов (ОР2). Распознавание изображений заменено случайным временем обслуживания.

Используется общая буферная память: любой кадр может занять любую свободную ячейку. Зоны потребовались бы при отдельных квотах памяти для разных камер.
